基础: torch 2.1.2 
图像: OpenCV 4.10 + NumPy 1.26
算法: mmcv 2.1.0 + mmdet 3.3.0 2.

安装：
# 创建并激活环境
conda create -n face_cv python=3.11 -y
conda activate face_cv

# 装PyTorch和OpenCV
pip install torch==2.1.2 torchvision==0.16.2
pip install "numpy<2.0" "opencv-python<4.11"

# 装MMDetection
pip install -U openmim
mim install "mmcv==2.1.0"
pip install mmdet

验证：
python -c "import torch, cv2, mmdet; print(f'good {torch.__version__} Ready | MPS: {torch.backends.mps.is_available()}')"
